## Структура v2

Header + левая панель на всю высоту + справа две панели 50/50 (`.rightcol`).

- **Панели универсальные**: каждая имеет комбобокс выбора контента. Виды (порядок в меню):
  Overview → Setup → Operations → Tool table → 3D Viewer. Holes удалён.
- Выбор вида, занятого другой панелью = **swap панелей**.
- Кнопка 24×24 сворачивает панель (иконки i-minimize/i-maximize «уголками»); свёрнутая сжимается
  по содержимому; левая в свёрнутом виде показывает вертикальную подпись `.panel__vlabel`.
  Справа может быть свёрнута только одна панель.
- Девайдеры (10px, фиолетовый градиент на ховер) ресайзят панели и возвращают свёрнутые
  (клик или драг). `makeDraggable` с порогом 3px.
- Поповеры все `position:fixed` (уходят от overflow:hidden), переворот вверх при нехватке места,
  закрытие по клику вне.

## Виды (что готово)

- **Overview**: плоские секции-аккордеоны через разделители (`.acc`, НЕ карточки): General,
  Material, **Setups (короткий список: имя + комбобокс оснастки)**, Holes, Machinability (issue).
  Сетка значений `.kv`: метка 96px, значения на одной оси; на узкой панели значение переносится
  под метку (flex-wrap, БЕЗ min-width:0).
- **Setup**: отдельный вид — аккордеон на каждый сетап: Part zero (чипы X/Y/Z `.coord`),
  Stock, Fixture, превью «3D view». Material убран (общий, живёт в Overview).
- **Operations**: дерево Setup → Part → операция. Инструмент ВСЕГДА на строке названия.
  Настройка отображаемых статов через кнопку-слайдеры: пресеты Compact (дефолт) / Time & feeds /
  Everything + чипы S/F/ap/ae/Time. Табличный вид ↔ компактный (параметры под названием),
  автопереключение по ширине (`opsNeededWidth()` + ResizeObserver).
- **Tool table**: два представления, переключатель в шапке панели (иконки i-rows / i-grid-view):
  - таблица `.dtable` (sticky шапка, строки 28px);
  - блоки **Tool & Assembly** (`.tool`): шапка с иконкой+T#, имя+тип, **сетка статов `.tspec`**
    (тихие метки + табличные значения, фикс. колонки 84px — НЕ пилюли); раскрытие по шеврону;
    внутри сегмент 2D|3D (актив — `--ec-blue-soft`), задизейбленный Holder, кнопка разворота
    (оверлей `.toolzoom`); превью — параметрический SVG из данных: 2D чертёж с размерами
    (⌀ сверху, OAL слева повёрнуто, выноска R) + осевая; 3D — градиентный рендер с держателем.
  - **Настройки отображения** (та же кнопка-слайдеры, общая `renderStatsMenu(view)`):
    статы ⌀/OAL/LOC/Z/Time/H/Rc/H#/D#; пресеты Tool presetting (дефолт: ⌀ OAL Z H, «on the
    machine») / Control offsets (H Rc H# D#, «into the CNC») / Everything. Один набор управляет
    и колонками таблицы, и сеткой в блоках. Легенда: H = tool length, Rc = ⌀/2, H#/D# = NC регистры.
- **3D Viewer**: ghost-заглушка (следующий кандидат на проработку).

## Данные (v2/app.js)

- `OPS` — 16 операций `{id,name,type,tool,time,params:{n,vf,fz,ap,ae,plunge}}`.
- `SETUPS` — setup1 (3 части/11 операций), setup2 (collapsed, 2 части/5), `wp:{x,y,z,stock,fixture}`.
- `TOOLS` — 5 инструментов `{tno,name,kind,dia,shank,flutes,fluteLen,lenBelowH,oal,cornerRad,hreg,dreg}`;
  у T137 регистры null (показ «—»). `toolTime()` — сумма времени операций инструментом.
