## Правила работы (важно)

1. Всё строить строго по **ENCY Core** (скилл `ency-core-design`). Если компонента/правила нет —
   спросить Руслана, не выдумывать.
2. **Радиусы**: база кнопка/контрол 4px, вложенность наружу: контрол 4 + отступ 4 = панель/поповер 8,
   дальше 12. Отступы кратны 4 (тонкая подстройка кратна 2).
3. **Без капслока нигде** (заголовки, роли, секции).
4. Плотность: контролы 24px, строки списков 24–28px, шрифты 11–12px, шапка панели 36px.
5. **Коммитить только по явной команде «зафиксируй»**. Публикация на GitHub — отдельный
   процесс (см. «Публикация»), она НЕ коммитит локальную историю.
6. Референсы прислал = «понимай смысл», аккуратный дизайн придумываем сами под систему.
7. Прежде чем делать — думать; при сомнении в правилах системы — спрашивать.

## Структура v2

Header + левая панель на всю высоту + справа две панели 50/50 (`.rightcol`).

- **Панели универсальные**: каждая имеет комбобокс выбора контента. Виды (порядок в меню):
  Overview → Operations → Tool table → 3D Viewer (Setup влит в Overview, Holes удалён;
  чек-лист — отдельный режим, не вид).
- Выбор вида, занятого другой панелью = **swap панелей**.
- Кнопка 24×24 сворачивает панель (иконки i-minimize/i-maximize «уголками»); свёрнутая сжимается
  по содержимому; левая в свёрнутом виде показывает вертикальную подпись `.panel__vlabel`.
  Справа может быть свёрнута только одна панель.
- Девайдеры (10px, фиолетовый градиент на ховер) ресайзят панели и возвращают свёрнутые
  (клик или драг). `makeDraggable` с порогом 3px.
- Поповеры все `position:fixed` (уходят от overflow:hidden), переворот вверх при нехватке места,
  закрытие по клику вне.
